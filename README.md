# igotify-assistant

Compose file for the [iGotify Notification Assistant](https://github.com/androidseb25/iGotify-Notification-Assistent),
which relays messages from Gotify (notify.gatewayy.net) to the iGotify iOS app through Apple's push service.

Hosted on the xCloud VPS at https://igotify.gatewayy.net. In the iGotify app: Gotify URL `https://notify.gatewayy.net`,
assistant URL `https://igotify.gatewayy.net`, then log in with the Gotify user.
